# PUNIFY — President University Student Printing & Service Hub

PUNIFY adalah platform digital layanan percetakan, pengetikan akademik, merchandise, dan pengantaran langsung ke asrama mahasiswa President University, Cikarang.

---

## Layanan Utama

1. **Print Dokumen & Skripsi:** Kertas A4 (70gsm & 80gsm), opsi Hitam Putih / Berwarna, jilid lakban, spiral kawat, atau hardcover skripsi.
2. **Fotokopi & Scan Digital:** Fotokopi cepat & digitalisasi dokumen ke PDF.
3. **Pembuatan Name Tag:** Pin akrilik, magnet, atau peniti dengan insert paper high-res.
4. **Jasa Ketik Tugas & Makalah:** Format APA/IEEE rapi sesuai pedoman kampus PresUniv.
5. **Gantungan Kunci Akrilik Custom:** Double sided akrilik 4x6 cm atau 5x5 cm.
6. **Academic Translation:** Terjemahan dokumen abstrak atau jurnal (Inggris - Indonesia).

---

## Fitur Unggulan

- **Real-Time Client-Side PDF Page Detection:** Menghitung total lembar file PDF secara langsung saat upload.
- **Simulator Gateway QRIS Interaktif:** Menghitung waktu mundur 15 menit, verifikasi multi-e-wallet (BCA, GoPay, ShopeePay, Dana, OVO), dan audio haptic synthesizer.
- **Dual-Mode Tracking:**
  - **Tampilan Mahasiswa:** Cek status pengerjaan, estimasi waktu tiba, kurir pengantar, dan bukti nota cetak.
  - **Panel Operator Cetak (Admin Desk):** Meja kerja operasional untuk update antrean status dan assign kurir asrama.
- **Direct WhatsApp Dispatch:** Integrasi rincian pesanan langsung ke admin WhatsApp resmi `0878-9519-7606`.
- **Drop Asrama Mahasiswa:** Pengantaran langsung ke meja satpam / lobby Student Housing (Dormitory) PresUniv.

---

## Tech Stack

- **Framework:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS (Clean Light Mode Theme)
- **Icons:** Lucide React
- **Audio Synthesizer:** Native Web Audio API
- **Deployment:** Netlify Ready (`netlify.toml` & `_redirects` included)

---

## Local Development

```bash
# Clone repository
git clone https://github.com/prince-salman/punify.git
cd punify

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
